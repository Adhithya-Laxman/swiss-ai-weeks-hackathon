# Sound Files for Mario's World Adventure

Add these 4 MP3 sound files to this directory:

## Required Sound Files:

1. **Jump.mp3** - Played when clicking on emoji locations
   - Suggested: Short, bouncy sound effect
   - Duration: 0.5-1 second

2. **End.mp3** - Played at the end of the game
   - Suggested: Victory/fanfare sound
   - Duration: 2-3 seconds

3. **Support.mp3** - Played when clicking "I SUPPORT" button
   - Suggested: Positive/encouraging sound
   - Duration: 1-2 seconds

4. **Start.mp3** - Played when clicking "START" button
   - Suggested: Game start/beginning sound
   - Duration: 1-2 seconds

## File Format:
- Format: MP3
- Quality: 128kbps or higher
- Sample Rate: 44.1kHz

## Usage:
The game will automatically load these sounds when it starts. If any sound file is missing, the game will continue to work but without audio for that specific action.

## Volume:
Default volume is set to 50%. You can adjust this in the `loadSounds()` function in `game.js` if needed.
